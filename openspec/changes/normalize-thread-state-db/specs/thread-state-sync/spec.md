## ADDED Requirements

### Requirement: スレッド状態の共通永続化
システムはスレッドごとの最新レス数、最終既読レス番号、最初の新着レス番号を、板画面・タブ一覧・スレッド画面から共通に参照できる永続状態として管理しなければならないMUST。共通状態は同一 `threadId` につき 1 件を正本とし、タブを閉じても保持されなければならないMUST。

#### Scenario: 同一スレッドの状態を1件に統合する
- **WHEN** 同じ `threadId` のスレッドが板画面、タブ一覧、スレッド画面の複数箇所から参照される
- **THEN** システムは同一の共通スレッド状態から最新レス数、最終既読レス番号、最初の新着レス番号を取得する

#### Scenario: タブを閉じてもスレッド状態を保持する
- **WHEN** ユーザーが開いているスレッドタブを閉じる
- **THEN** システムはタブ固有状態を削除し、共通スレッド状態の最新レス数と既読状態を保持する

### Requirement: 画面間の新着レス数同期
システムは板画面のスレ一覧とタブ一覧のスレ一覧で、同一スレッドの新着レス数を同じ共通スレッド状態と同じ計算規則から導出しなければならないMUST。どちらかの画面でレス数または既読状態が更新された場合、もう一方の画面にも同じ新着レス数が反映されなければならないMUST。

#### Scenario: 板更新後にタブ一覧へ新着レス数を反映する
- **WHEN** 板画面のスレ一覧更新で、開いているスレッドの最新レス数が増加する
- **THEN** システムは共通スレッド状態を更新し、タブ一覧の同一スレッドに同じ新着レス数を表示する

#### Scenario: タブ一覧更新後に板画面へ新着レス数を反映する
- **WHEN** タブ一覧のスレッド更新で、板画面にも表示されるスレッドの最新レス数が増加する
- **THEN** システムは共通スレッド状態を更新し、板画面の同一スレッドに同じ新着レス数を表示する

#### Scenario: スレッド閲覧後に新着レス数をクリアする
- **WHEN** ユーザーがスレッド画面で新着レス範囲を既読位置まで閲覧する
- **THEN** システムは共通スレッド状態の最終既読レス番号を更新し、板画面とタブ一覧の同一スレッドの新着レス数を同じ値に更新する

### Requirement: 更新経路の統一
システムは板更新、タブ一覧更新、スレッド閲覧・更新、既読位置更新の各経路で、共通スレッド状態を更新しなければならないMUST。レス数と既読状態を更新する処理は、状態の不整合を避けるためトランザクション内で整合した値として保存されなければならないMUST。

#### Scenario: 板更新で最新レス数を保存する
- **WHEN** subject.txt の取得によりスレッドのレス数が判明する
- **THEN** システムは板一覧キャッシュを更新するとともに、対象スレッドの共通スレッド状態の最新レス数を更新する

#### Scenario: タブ一覧更新で最新レス数を保存する
- **WHEN** タブ一覧の更新処理により開いているスレッドのレス数が判明する
- **THEN** システムは対象スレッドの共通スレッド状態の最新レス数を更新し、タブ固有状態にはレス数の正本を保存しない

#### Scenario: 既読位置更新を保存する
- **WHEN** スレッド画面がユーザーの最終既読レス番号を更新する
- **THEN** システムは対象スレッドの共通スレッド状態に最終既読レス番号と新着開始レス番号を保存する

### Requirement: 既存データの移行
システムは DB スキーマ変更時に、既存のタブ、履歴、板一覧キャッシュに保存されているスレッド情報から共通スレッド状態を生成しなければならないMUST。移行後も開いていたタブの並び順、スクロール位置、既読状態、最新レス数は可能な限り保持されなければならないMUST。

#### Scenario: タブ由来の状態を移行する
- **WHEN** 既存 DB に開いているスレッドタブが存在する状態でアプリが新スキーマへ移行する
- **THEN** システムはタブの `threadId`、レス数、既読状態から共通スレッド状態を作成し、タブの並び順とスクロール位置を保持する

#### Scenario: 履歴由来の状態を移行する
- **WHEN** 既存 DB に閲覧履歴が存在する状態でアプリが新スキーマへ移行する
- **THEN** システムは履歴の `threadId`、レス数、既読状態から共通スレッド状態を作成する

#### Scenario: 複数の移行元に同一スレッドが存在する
- **WHEN** 同じ `threadId` がタブ、履歴、板一覧キャッシュの複数箇所に存在する
- **THEN** システムは 1 件の共通スレッド状態へ統合し、最新レス数は利用可能な値のうち最大値を保持する

### Requirement: タブ固有状態とスレッド状態の分離
システムは開いているスレッドタブの並び順とスクロール位置を、スレッドのレス数・既読状態とは分離して管理しなければならないMUST。タブ一覧の表示モデルは、タブ固有状態と共通スレッド状態を合成して生成されなければならないMUST。

#### Scenario: タブ一覧表示モデルを合成する
- **WHEN** ユーザーがタブ一覧のスレッド一覧を表示する
- **THEN** システムはタブ固有状態から並び順とスクロール位置を取得し、共通スレッド状態からタイトル、最新レス数、新着レス数、既読状態を取得して表示する

#### Scenario: タブ保存でレス数の正本を更新しない
- **WHEN** システムが開いているスレッドタブの並び順またはスクロール位置を保存する
- **THEN** システムはタブ固有状態を保存し、レス数・既読状態の正本をタブ保存処理で上書きしない
