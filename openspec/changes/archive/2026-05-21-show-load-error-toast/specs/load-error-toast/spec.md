## ADDED Requirements

### Requirement: 板読み込み失敗の Toast 通知
システムは板画面で板一覧の読み込みまたは更新に失敗した場合、ユーザーに Toast で失敗を通知しなければならないMUST。Toast は読み込み試行 1 回につき最大 1 回だけ表示されなければならないMUST。

#### Scenario: 板読み込み中に例外が発生する
- **WHEN** 板画面の読み込み処理中に例外が発生する
- **THEN** システムは板読み込み失敗を表す Toast を 1 回表示する

#### Scenario: 板読み込みが失敗結果を返す
- **WHEN** 板画面の読み込み処理が例外ではなく失敗結果として終了する
- **THEN** システムは板読み込み失敗を表す Toast を 1 回表示する

### Requirement: スレッド読み込み失敗の Toast 通知
システムはスレ画面でスレッド本文の読み込みまたは更新に失敗した場合、ユーザーに Toast で失敗を通知しなければならないMUST。Toast は読み込み試行 1 回につき最大 1 回だけ表示されなければならないMUST。

#### Scenario: スレッド読み込み中に例外が発生する
- **WHEN** スレ画面の読み込み処理中に例外が発生する
- **THEN** システムはスレッド読み込み失敗を表す Toast を 1 回表示する

#### Scenario: スレッド読み込みが失敗結果を返す
- **WHEN** スレ画面の読み込み処理が例外ではなく失敗結果として終了する
- **THEN** システムはスレッド読み込み失敗を表す Toast を 1 回表示する

### Requirement: 読み込み失敗 Toast の one-shot 表示
システムは読み込み失敗 Toast を UIState に永続保持せず、画面側が収集する one-shot event として扱わなければならないMUST。画面の再コンポーズだけで同じ Toast を再表示してはならないMUST NOT。

#### Scenario: 読み込み失敗後に画面が再コンポーズされる
- **WHEN** 読み込み失敗 Toast が表示された後、同じ画面が再コンポーズされる
- **THEN** システムは同じ失敗 event による Toast を再表示しない

### Requirement: 読み込み失敗の詳細ログ出力
システムは読み込み失敗 Toast を表示する場合、調査用に失敗原因をログへ記録しなければならないMUST。Toast の文言はユーザー向けの短い文言とし、例外詳細をそのまま表示してはならないMUST NOT。

#### Scenario: 例外に詳細メッセージが含まれる
- **WHEN** 読み込み処理が詳細メッセージを持つ例外で失敗する
- **THEN** システムは詳細をログへ記録し、Toast には画面種別に応じた短い失敗文言を表示する
