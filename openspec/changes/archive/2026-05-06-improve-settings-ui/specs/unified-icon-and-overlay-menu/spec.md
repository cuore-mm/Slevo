## ADDED Requirements

### Requirement: 汎用アンカー選択メニューの提供
システムは `AnchoredOverlayMenu` を用いた汎用選択メニューを提供しなければならない（MUST）。汎用選択メニューは選択肢リスト、現在選択中の値、選択時コールバック、dismiss コールバックを受け取り、選択済み項目を primary color、太字、右端チェックアイコンで表示しなければならない（MUST）。

#### Scenario: 選択済み項目を共通表現で表示する
- **WHEN** 汎用選択メニューが現在選択中の値を含む選択肢リストを表示する
- **THEN** システムは該当項目のテキストを primary color と太字で表示し、右端にチェックアイコンを表示する

#### Scenario: 選択時に値を通知して閉じる
- **WHEN** ユーザーが汎用選択メニュー内の項目を押下する
- **THEN** システムは押下された値を選択時コールバックへ渡し、メニューを閉じる

### Requirement: 設定項目選択メニューのアンカーオーバーレイ化
システムは設定画面内の選択式項目である全般のテーマ設定およびスレッド表示のデフォルト並び順設定を、汎用アンカー選択メニューで表示しなければならない（MUST）。メニューは押下された設定項目を基準に重ね表示し、既存の dismiss 契約を維持しなければならない（MUST）。

#### Scenario: 全般テーマ設定メニューがアンカー重ね表示される
- **WHEN** ユーザーが全般設定画面のテーマ設定項目を押下する
- **THEN** システムは汎用アンカー選択メニューをテーマ設定項目基準で重ね表示する

#### Scenario: スレッド並び順設定メニューがアンカー重ね表示される
- **WHEN** ユーザーがスレッド設定画面のデフォルト並び順項目を押下する
- **THEN** システムは汎用アンカー選択メニューをデフォルト並び順項目基準で重ね表示する

#### Scenario: 設定項目メニュー外タップや戻る操作で閉じる
- **WHEN** ユーザーが設定項目メニューの外側をタップするか戻る操作を行う
- **THEN** システムは `AnchoredOverlayMenu` を dismiss し、選択前の保存済み設定を維持する
