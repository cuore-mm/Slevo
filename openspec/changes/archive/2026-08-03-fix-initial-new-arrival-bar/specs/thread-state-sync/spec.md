## ADDED Requirements

### Requirement: 新着件数と初回未読境界の統一
システムは、閲覧履歴が存在するスレッドの新着件数を、共通客観状態の最新レス数から履歴紐づき既読状態の最終既読レス番号を引いた0以上の値として導出しなければならない（MUST）。システムは、スレッド画面の初回未読境界を同じ最終既読レス番号の次として導出しなければならない（MUST）。最初の新着レス番号の有無によって、この件数または境界を変えてはならない（MUST NOT）。

#### Scenario: 板一覧の新着件数とスレッド初回境界を一致させる
- **WHEN** 共通客観状態の最新レス数が110、履歴の最終既読レス番号が100である
- **THEN** システムは板一覧とタブ一覧へ新着10件を表示し、スレッド初回ロードでは101番を未読境界にする

#### Scenario: 最初の新着レス番号がnullでも同じ規則を使用する
- **WHEN** 共通客観状態の最新レス数が110、履歴の最終既読レス番号が100、最初の新着レス番号が `null` である
- **THEN** システムは新着10件と101番の未読境界を導出する

#### Scenario: 最初の新着レス番号が既読位置の次と異なっても最終既読位置を使用する
- **WHEN** 履歴の最初の新着レス番号が最終既読レス番号の次と一致しない
- **THEN** システムは最終既読レス番号を使用して新着件数と初回未読境界を導出する

#### Scenario: 履歴がなければ新着件数と初回境界を作らない
- **WHEN** 共通客観状態は存在するが閲覧履歴が存在しない
- **THEN** システムは新着件数を0とし、スレッド画面の初回未読境界を作らない

### Requirement: 初回未読境界のセッション分離
システムは、スレッド画面セッション開始時に履歴紐づき既読状態から初回未読境界を取り込み、その後の既読状態更新とは独立した画面セッション状態として保持しなければならない（MUST）。

#### Scenario: 既読位置の永続化後も表示境界を保持する
- **WHEN** スレッド画面の表示によって履歴の最終既読レス番号が更新される
- **THEN** システムは板一覧とタブ一覧の新着件数を更新し、表示中スレッドの初回未読境界は維持する

#### Scenario: 新しい画面セッションでは最新の既読位置を取り込む
- **WHEN** スレッドタブを閉じた後、同じスレッドを新しいタブとして開く
- **THEN** システムは新しい画面セッション開始時点の履歴既読状態から初回未読境界を再計算する
