## ADDED Requirements

### Requirement: スレッド更新後のレスポップアップ安定表示
システムはレスポップアップの表示対象を、投稿 UI モデルの等価性ではなくスレッド内の投稿番号で管理しなければならないMUST。スレッド更新により投稿 UI モデルや派生情報が再生成された場合でも、表示中のレスポップアップは保持した投稿番号から最新の投稿を解決して描画し、古い投稿モデルの照合失敗や負の添字アクセスでクラッシュしてはならないMUST NOT。

#### Scenario: ポップアップ表示中にスレッドが更新される
- **WHEN** ユーザーがレスポップアップを表示している状態でスレッド更新により投稿一覧と派生情報が再生成される
- **THEN** システムはポップアップが保持する投稿番号から最新の投稿を解決して表示を継続する
- **AND** システムは古い投稿 UI モデルを最新投稿一覧へ `indexOf` で照合する前提に依存しない

#### Scenario: 最新投稿一覧に対象投稿番号が存在しない
- **WHEN** レスポップアップが保持する投稿番号に対応する投稿が最新投稿一覧から解決できない
- **THEN** システムは該当投稿を描画対象から除外する
- **AND** システムは投稿一覧または派生情報へ範囲外添字でアクセスしない

#### Scenario: ID順序派生情報が投稿一覧と一時的に不整合になる
- **WHEN** レスポップアップ描画時に投稿番号から算出した添字が `idIndexList` の範囲外になる
- **THEN** システムは安全な既定値で ID 順序表示を継続する
- **AND** システムは `IndexOutOfBoundsException` を発生させない

### Requirement: 投稿番号ベースのポップアップ操作維持
システムはレスポップアップの表示対象を投稿番号で管理する場合でも、返信番号、返信元、ID、ツリー、多段ポップアップ、画像 shared transition の既存操作を維持しなければならないMUST。ポップアップ内の各投稿に紐づく返信元、ID 集計、my 投稿、NG 投稿、画像識別は、描画時点の最新状態と投稿番号から導出されなければならないMUST。

#### Scenario: ポップアップ内で返信番号をタップする
- **WHEN** ユーザーが投稿番号ベースで表示されたレスポップアップ内の返信番号をタップする
- **THEN** システムはタップ対象の投稿番号と最新投稿一覧に基づいて次のレスポップアップを表示する

#### Scenario: ポップアップ内でIDをタップする
- **WHEN** ユーザーが投稿番号ベースで表示されたレスポップアップ内の ID をタップする
- **THEN** システムは最新投稿一覧から同一 ID の投稿番号を抽出して ID ポップアップを表示する

#### Scenario: 多段ポップアップで画像を表示する
- **WHEN** ユーザーが投稿番号ベースで表示された多段レスポップアップ内の画像サムネイルを表示する
- **THEN** システムはポップアップ識別子と投稿番号を使った shared transition 識別を維持する
- **AND** システムは階層ごとの画像サムネイル表示を維持する

#### Scenario: 投稿番号ベースで連続同一ポップアップを判定する
- **WHEN** ユーザーが現在表示中の最上位ポップアップと同じ投稿番号集合のポップアップを連続して開こうとする
- **THEN** システムは投稿 UI モデルのインスタンスや表示補助情報の差分に依存せず、投稿番号集合に基づいて同一表示を判定する
