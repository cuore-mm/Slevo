## MODIFIED Requirements

### Requirement: タブ長押しアクションメニュー
システムはタブ一覧（板タブ一覧・スレッドタブ一覧）のカードを長押ししたとき、長押し対象カードに紐づくタブ専用の`AnchoredTabActionMenu`を表示しなければならないMUST。メニューは「詳細」「タブを固定」または「タブの固定を解除」「タブを閉じる」「タブを選択」を表示し、各項目の先頭に意味を表すアイコンを表示しなければならないMUST。「タブを閉じる」は破壊的操作として赤字で表示しなければならないMUST。

#### Scenario: 未固定タブを長押ししてメニューを表示する
- **WHEN** ユーザーが未固定の板タブまたはスレッドタブを長押しする
- **THEN** システムは長押しカード位置に紐づく`AnchoredTabActionMenu`を表示し、「詳細」「タブを固定」「タブを閉じる」「タブを選択」を表示する

#### Scenario: 固定済みタブを長押しして解除メニューを表示する
- **WHEN** ユーザーが固定済みの板タブまたはスレッドタブを長押しする
- **THEN** システムは`AnchoredTabActionMenu`に「詳細」「タブの固定を解除」「タブを閉じる」「タブを選択」を表示する

#### Scenario: タブを閉じる項目を赤字で表示する
- **WHEN** `AnchoredTabActionMenu`が表示される
- **THEN** システムは「タブを閉じる」を破壊的操作として赤字で表示する

#### Scenario: メニュー項目にアイコンを表示する
- **WHEN** `AnchoredTabActionMenu`が表示される
- **THEN** システムは「詳細」「タブを固定」または「タブの固定を解除」「タブを閉じる」「タブを選択」の各項目の先頭に、項目の意味を表すアイコンを表示する

#### Scenario: 破壊的操作のアイコン色を揃える
- **WHEN** `AnchoredTabActionMenu`が表示される
- **THEN** システムは「タブを閉じる」のテキストと先頭アイコンを同じ破壊的操作色で表示する

#### Scenario: タブ左端に揃えてメニューを表示する
- **WHEN** ユーザーが板タブまたはスレッドタブを長押しする
- **THEN** システムはメニューの左端を長押し対象タブの左端に概ね揃えて表示し、画面外にはみ出す場合は画面内に収める

#### Scenario: 空きが大きい上下方向にメニューを表示する
- **WHEN** ユーザーが画面下寄りのタブを長押しする
- **THEN** システムはメニューを長押し対象タブの上側に、タブと重ならない間隔を空けて表示する

#### Scenario: 画面上寄りのタブでは下側にメニューを表示する
- **WHEN** ユーザーが画面上寄りのタブを長押しする
- **THEN** システムはメニューを長押し対象タブの下側に、タブと重ならない間隔を空けて表示する

#### Scenario: メニュー外操作で選択を解除する
- **WHEN** `AnchoredTabActionMenu`表示中にユーザーがメニュー外をタップする
- **THEN** システムはメニューを閉じ、タブの長押し選択状態を解除する

### Requirement: タブ一覧の一括クローズメニュー
システムは、タブ一覧の通常表示中、検索ボタンの右にアクセシブルな「その他」ボタンを表示しなければならない（SHALL）。システムは、このボタンをアンカーとする`AnchoredTabActionMenu`に「全てのタブを閉じる」と「タブを選択」を表示しなければならない（SHALL）。

#### Scenario: その他ボタンからメニューを開く
- **WHEN** 利用者がタブ一覧上部の「その他」ボタンを押す
- **THEN** システムは押されたボタンをアンカーとして「全てのタブを閉じる」と「タブを選択」を持つメニューを表示する

#### Scenario: 支援技術でその他ボタンを識別する
- **WHEN** 支援技術がタブ一覧上部の操作を読み上げる
- **THEN** システムは検索操作とその他操作を別々に識別可能なcontent descriptionで公開する

#### Scenario: メニューを取り消す
- **WHEN** 利用者がメニュー外を押すかBack操作を行う
- **THEN** システムは一括クローズまたは選択モード開始を実行せずにメニューを閉じる

#### Scenario: 検索モードへ切り替える
- **WHEN** タブ一覧が検索モードを表示する
- **THEN** システムは検索入力を既存どおり表示し、通常表示用の検索ボタンとその他ボタンを表示しない
