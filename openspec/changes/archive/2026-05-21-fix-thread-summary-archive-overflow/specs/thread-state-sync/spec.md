## ADDED Requirements

### Requirement: 板更新キャッシュ障害に影響されない共通客観状態同期
システムは subject.txt の板更新によりスレッド一覧キャッシュと共通客観状態を更新する際、大量の過去スレッドアーカイブ処理が SQLite の SQL 変数上限を超えないように処理し、共通客観状態への最新レス数・タイトル・板情報の同期を完了しなければならないMUST。

#### Scenario: 大量の過去スレッドがある板で共通客観状態を同期する
- **WHEN** 対象板に大量のアーカイブ済み過去スレッドが存在し、subject.txt の取得により現役スレッドのレス数とタイトルが判明する
- **THEN** システムは過去スレッドの再アーカイブ処理で DB エラーを発生させず、現役スレッドの共通客観状態を更新する

#### Scenario: subject.txt から消えた現役スレッドがある板で共通客観状態を同期する
- **WHEN** subject.txt の取得により一部の現役スレッドが板一覧から消えたことが判明する
- **THEN** システムは消えた現役スレッドの板一覧キャッシュを安全にアーカイブし、subject.txt に残るスレッドの共通客観状態を更新する
