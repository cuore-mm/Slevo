## ADDED Requirements

### Requirement: タブ一覧選択はタブ選択状態を更新する
システムはタブ一覧のカード選択時、対象タブを TabSessionStore の選択中タブとして設定しなければならないMUST。カード選択は同一タブ種別の navigation back stack を追加で積んではならないMUST NOT。

#### Scenario: 板タブカードを選択する
- **WHEN** ユーザーがタブ一覧で板タブカードを選択する
- **THEN** システムは対象板タブを選択中板タブとして設定し、板画面種別でそのタブを表示する

#### Scenario: スレッドタブカードを選択する
- **WHEN** ユーザーがタブ一覧でスレッドタブカードを選択する
- **THEN** システムは対象スレッドタブを選択中スレッドタブとして設定し、スレッド画面種別でそのタブを表示する

#### Scenario: シート内タブ選択でシートを閉じる
- **WHEN** ユーザーが板またはスレッド画面内のタブ一覧シートでタブを選択する
- **THEN** システムは選択状態を更新した後、タブ一覧シートを閉じる
