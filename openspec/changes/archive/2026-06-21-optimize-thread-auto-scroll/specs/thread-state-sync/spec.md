## ADDED Requirements

### Requirement: 自動スクロール中の表示合成負荷抑制
システムはスレッド画面の自動スクロール中にスクロール位置が連続保存される場合でも、スクロール位置だけの変更によってスレッド表示用 `ThreadUiState` の重い再合成を発火させてはならないMUST NOT。スクロール位置保存はタブ復元用状態として扱い、投稿行、検索、NG、返信数、新着境界などの表示内容に影響しない限り、表示行再計算の入力にしてはならないMUST NOT。

#### Scenario: 自動スクロール中にスクロール位置が保存される
- **WHEN** 自動スクロールにより `firstVisibleItemIndex` または `firstVisibleItemScrollOffset` だけが更新される
- **THEN** システムは対象スレッドの保存済みスクロール位置を更新し、`ThreadUiState` の投稿行再合成をスクロール位置変更だけでは実行しない

#### Scenario: 表示内容に関係するタブ情報が変わる
- **WHEN** タイトル、boardId、レス数、新着境界、bookmark 色、pin 状態など表示内容に関係するタブ情報が更新される
- **THEN** システムは対象スレッドの `ThreadUiState` を再合成し、表示へ反映する

### Requirement: 自動スクロール Effect の自己再起動抑制
システムは自動スクロールを進めるための programmatic scroll によって、自動スクロール Effect をキャンセル・再起動させてはならないMUST NOT。自動スクロールの駆動条件は `isAutoScroll` と表示対象の変化を基準とし、`scrollBy` 自身が発生させるスクロール進行状態を Effect の再起動 key として扱ってはならないMUST NOT。

#### Scenario: 自動スクロールが継続する
- **WHEN** 自動スクロールが有効な状態でシステムが `LazyListState` を programmatic scroll する
- **THEN** システムは programmatic scroll によるスクロール進行状態の変化だけで自動スクロール Effect を再起動しない

### Requirement: 手動スクロール後の自動スクロール再開
システムは自動スクロール中にユーザーが手動スクロールした場合、自動スクロール設定を解除してはならないMUST NOT。ユーザー操作中は自動スクロールを一時停止し、ユーザー操作の終了後に自動スクロールを再開しなければならないMUST。

#### Scenario: 自動スクロール中にユーザーがドラッグする
- **WHEN** 自動スクロールが有効な状態でユーザーがスレッド一覧を手動ドラッグする
- **THEN** システムはドラッグ中だけ自動スクロールを一時停止し、`isAutoScroll` は有効状態のまま維持する

#### Scenario: ユーザー操作が終了する
- **WHEN** 自動スクロール中のユーザー手動スクロールが終了する
- **THEN** システムは自動スクロールを再開し、ユーザーが再度自動スクロールボタンを押す必要がない

### Requirement: スクロール位置復元の維持
システムは自動スクロールの滑らかさを改善した後も、タブ切替、画面離脱、画面破棄時に保存済みスクロール位置を復元できなければならないMUST。自動スクロール中の表示合成負荷抑制は、スクロール位置保存そのものを失わせてはならないMUST NOT。

#### Scenario: 自動スクロール中にタブを切り替える
- **WHEN** ユーザーが自動スクロール中に別のスレッドタブへ切り替える
- **THEN** システムは切り替え時点のスクロール位置を保存し、元のスレッドタブへ戻ったときにその位置を復元する

#### Scenario: 自動スクロール中に画面を離れる
- **WHEN** ユーザーが自動スクロール中にスレッド画面を離れる
- **THEN** システムは離脱時点のスクロール位置を保存し、再表示時にその位置を復元する
