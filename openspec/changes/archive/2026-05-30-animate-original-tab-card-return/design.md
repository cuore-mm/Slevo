## Context

現在のタブ長押し選択では、選択対象の元カードを `alpha(0f)` で透明化し、overlay 上に再描画した floating card を表示している。長押し開始時と解除時の scale animation は floating card 側が担当し、解除アニメーション完了後に元カードを通常表示へ戻す構造になっている。

この構造では、前面表示中のカードと一覧内の元カードが別の描画主体になる。選択解除時も floating card が縮小し、完了後に元カードが即時復帰するため、ユーザーには「元のカードへ戻った」よりも「前面カードが消えて元カードが現れた」ように見えやすい。

## Goals / Non-Goals

**Goals:**

- 長押し中、元カードも内部状態として選択中スケールを持つ。
- 長押し選択解除時、元カードを表示状態へ戻し、元カード側で `1.04 → 1.00` の復帰アニメーションを表示する。
- floating card は長押し中の前面表示とアクションメニューのアンカー表現に集中させる。
- 元カードと floating card が同時に不自然に見える二重表示を避ける。
- dim overlay、選択解除条件、下部操作群の維持、詳細 BottomSheet 表示、固定切替、削除操作の契約を維持する。

**Non-Goals:**

- タブ長押しメニューの項目、文言、アイコン、配置の変更。
- タブ固定状態、削除、詳細表示のデータモデル変更。
- LazyList の並び順やスクロール仕様の変更。
- 削除アニメーションの再設計。

## Decisions

### Decision 1: 元カードにも選択中 scale を持たせる

元カードは長押し選択中に透明化されたまま、scale を通常値から選択中値へ進める。これにより、解除時に元カードを表示へ戻した時点で floating card と同じ拡大状態から復帰アニメーションを始められる。

代替案として、解除時だけ元カードを一瞬 `1.04` に snap して縮小する方法もあるが、長押し中の内部状態と表示状態が分離し、タイミングによってちらつきが出やすいため採用しない。

### Decision 2: 解除時の縮小は元カードが担当する

長押し解除時は、floating card の戻り縮小を主アニメーションにしない。元カードを表示状態に戻し、元カード側で選択中スケールから通常スケールへアニメーションする。

代替案として、現在と同じく floating card を縮小してから元カードを復帰させる方法がある。この方法は overlay 内だけで完結するが、戻り先の元カードとの連続性が弱いため採用しない。

### Decision 3: floating card は解除時に短く消すか即時破棄する

解除開始後、floating card は元カードの復帰アニメーションと競合しないように扱う。基本方針は、元カードを表示状態へ戻すタイミングで floating card を即時破棄するか、極短い fade out のみを行う。scale の戻り表現は元カードへ一本化する。

代替案として、floating card と元カードを同時に縮小する方法もあるが、同じカードが二重に見える可能性が高く、端末性能や再コンポーズタイミングでちらつきや濃淡差が出るため採用しない。

### Decision 4: アニメーション状態は UI 層に閉じる

復帰アニメーションの進行状態は `TabListCard` またはその近傍の composable state として管理し、タブの永続 state や Coordinator には持ち込まない。ViewModel は選択対象と bounds の管理に留め、描画トランジションの細部は UI 層で扱う。

代替案として、ViewModel に「解除アニメーション中」状態を追加する方法もあるが、表示だけの一時状態が UI state 全体に広がり、詳細表示やページ切替との責務境界が曖昧になるため採用しない。

## Risks / Trade-offs

- 二重表示が発生する → floating card の破棄または fade out と、元カード alpha 復帰の順序を明確にし、同時に完全表示しない。
- 元カードが dim overlay の下で見える → 長押し中の元カードは透明のまま維持し、解除時だけ表示へ戻す。
- LazyList の再配置で戻り位置がずれる → 復帰アニメーションは一覧内の現在位置で行い、スクロールやページ切替で対象が消えた場合はアニメーションを省略できる設計にする。
- アニメーション状態が複雑化する → scale 値、alpha、floating card 生存期間の責務を分け、ViewModel に描画専用の状態を増やさない。
- 既存の退場アニメーション仕様との競合 → 削除アニメーション中は長押し選択を開始しない既存条件を維持し、長押し解除の復帰 animation と削除 animation を同時に走らせない。
