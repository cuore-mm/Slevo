## Why

スレッド画面で自動スクロールを有効にしたままタブ切り替えや画面遷移を行うと、復帰時にスクロール位置が数秒前の状態へ巻き戻る。スクロール位置の保存が連続更新中に遅延・未確定になっているため、画面を離れた瞬間の位置を復元できるようにする必要がある。

## What Changes

- スレッド画面のスクロール位置保存を、連続スクロール中でも一定間隔で最新化される方式へ変更する。
- タブ非アクティブ化、画面遷移、Composable 破棄時に、現在のスクロール位置を即時保存する。
- スレッド投稿一覧の行キーを、行インデックスには依存せず、レス番号と表示上の役割を組み合わせた安定キーへ変更し、Compose のスクロール位置維持を安定させる。
- 既存のタブ固有スクロール位置の永続化データ構造は維持し、DB スキーマ変更を伴わない範囲で修正する。

## Capabilities

### New Capabilities

- なし

### Modified Capabilities

- `thread-state-sync`: 開いているスレッドタブのスクロール位置を、連続スクロール中および画面離脱時にも最新位置として保存・復元する要件を追加する。

## Impact

- 影響範囲:
  - `BbsRouteScaffold` のスクロール位置監視・保存処理
  - `ThreadScaffold` から渡されるスレッドタブのスクロール保存経路
  - `ThreadDisplayTransformers` / `ThreadPostListContent` の LazyColumn item key 生成
- API・外部依存関係の追加はない。
- DB スキーマ変更は行わない想定。
- 回帰確認対象は、自動スクロール中のタブ切り替え、他画面遷移からの復帰、通常手動スクロール後の復元である。
