# Spec Delta

## MODIFIED Requirements

### Requirement: 不正な参照と巨大範囲の安全な処理
システムは取得済みの同一スレッド内に存在する正のレス番号だけを返信関係として解決しなければならない（SHALL）。返信先プレビューとその候補一覧ではNG・未取得の正の番号も状態表示の対象に保持し、安価行ごとに重複除去後1,000件の上限を適用しなければならない（SHALL）。0、逆順範囲、整数として表せない番号、不完全な範囲・カンマ表記は無効とし、部分的な単一安価として解釈してはならない（MUST NOT）。巨大範囲によって操作不能になってはならない（MUST NOT）。

#### Scenario: 巨大範囲を取得済みレスと照合する
- **WHEN** 100件取得済みのスレッドに`>>1-2147483647`が含まれる
- **THEN** 返信関係としては存在する1から100だけを解決する
- **AND** 安価だけの行の返信先候補としては1から1,000を保持し、101から1,000は未取得状態とし、上限超過を通知する
- **AND** どちらの処理でも範囲全体を列挙しない

#### Scenario: 無効な構文を先頭番号へ縮退させない
- **WHEN** 本文に`>>0`、`>>5-1`、`>>99999999999999999999`、`>>1-`、`>>1,`が含まれる
- **THEN** これらから参照先を生成せず、有効な別の安価と通常本文の表示は維持する

## ADDED Requirements

### Requirement: 返信先候補と返信元の除外方針の分離
システムは返信先プレビューの候補一覧ではNG・未取得番号を状態行として保持しなければならない（SHALL）。通常本文とポップアップ本文の安価リンク、ID・ツリー一覧の既存の対象選別を変更してはならない（MUST NOT）。返信元件数・返信元一覧・返信元プレビューおよび返信通知には従来どおりNGを含めてはならない（MUST NOT）。一時開示によって返信元や通知の対象を増やしてはならない（MUST NOT）。

#### Scenario: 返信先一覧では番号を保持する
- **WHEN** 返信先プレビューの候補がNGの1、未取得の2、正常の3であり、「ほか2件」を開く
- **THEN** 1のNG状態、2の未取得状態、3の通常レスを番号付きで表示する

#### Scenario: 通常の安価リンクの挙動を維持する
- **WHEN** 通常本文またはポップアップ本文の`>>1-3`リンクをタップし、1がNG、2が未取得、3が正常である
- **THEN** 既存どおり通常リンクのポップアップは3だけを表示する

#### Scenario: NGの返信元は引き続き除外する
- **WHEN** あるレスへの返信元が2、3、4で、3がNGであり、別の返信先表示で3を一時開示する
- **THEN** 返信件数は2、返信元一覧とプレビューの対象は2と4のままで、3のNG由来通知は抑止される
