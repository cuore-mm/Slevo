# Spec Delta

## MODIFIED Requirements

### Requirement: スレッド更新後のレスポップアップ安定表示
システムはレスポップアップの表示対象を投稿UIモデルの等価性ではなくスレッド内の投稿番号で管理し、更新後も最新の投稿を番号から解決しなければならない（MUST）。返信先候補一覧ではNGの取得済み番号を状態行に残し、取得済みレス数を超える番号は統合した未取得範囲として表示し、その他の一覧では従来の対象選別を維持しなければならない（MUST）。古い投稿モデルの照合失敗、負の添字、範囲外アクセスによってクラッシュしてはならない（MUST NOT）。

#### Scenario: ポップアップ表示中にスレッドが更新される
- **WHEN** ユーザーがレスポップアップを表示している状態でスレッド更新により投稿一覧と派生情報が再生成される
- **THEN** ポップアップが保持する投稿番号から最新の投稿を解決して表示を継続する
- **AND** 古い投稿UIモデルを最新投稿一覧へ等価照合する前提に依存しない

#### Scenario: 最新投稿一覧に対象投稿番号が存在しない
- **WHEN** 更新後の投稿数が減り、返信先ポップアップが保持する番号の一部を解決できない
- **THEN** 解決不能な番号を連続範囲へ集約して未取得状態を表示し、その他のポップアップでは該当投稿を描画対象から除外する
- **AND** 投稿一覧や派生情報へ範囲外添字でアクセスしない

#### Scenario: ID順序派生情報が投稿一覧と一時的に不整合になる
- **WHEN** ポップアップ描画時に投稿番号から算出した添字がID順序情報の範囲外になる
- **THEN** 安全な既定値でID順序表示を継続し、範囲外例外を発生させない

## ADDED Requirements

### Requirement: 返信先候補一覧の状態行とその場での開示
システムは返信先候補一覧に、選択済み一件を含む取得済み候補を元の出現順で表示し、正常は通常レス、NGは番号・「NGで非表示」・「表示」としなければならない（SHALL）。取得済みレス数を超える未取得番号は個別に展開せず、統合した未取得範囲を状態行で表示しなければならない（SHALL）。全件NG・未取得でも一覧を自動削除してはならない（MUST NOT）。NGの表示操作は同じポップアップのその行を通常レス形式へ切り替え「隠す」を表示し、隠す操作は元の状態行へ戻さなければならない（SHALL）。

#### Scenario: NGレスをその場で表示して隠す
- **WHEN** 返信先一覧内のNGレスの「表示」を押す
- **THEN** 新しいポップアップを開かず、その行に通常レスと「隠す」を表示する
- **AND** 「隠す」を押すと同じ行を番号とNG非表示状態へ戻す

#### Scenario: 全件参照不能でも一覧を維持する
- **WHEN** 候補がNG2件と未取得範囲1件である一覧を開く
- **THEN** 二つのNG状態と一つの未取得範囲を表示し、描画可能な通常レスがゼロでも一覧を閉じない

#### Scenario: 未来番号を一つの範囲状態にまとめる
- **WHEN** 100件取得済みのスレッドで返信先候補が`90-200`である一覧を開く
- **THEN** 90から100は取得済み候補として表示し、101から200は一つの未取得範囲行にまとめる
- **AND** 101から200を個別行として生成しない

#### Scenario: 開示状態は表示箇所ごとに独立する
- **WHEN** 同番号がメインのプレビューと二つのポップアップにあり、一つのポップアップで開示する
- **THEN** そのポップアップの行だけを開示し、他の箇所とNG設定は変更しない
- **AND** そのポップアップを閉じて開き直すとNG非表示状態から始める

#### Scenario: NG更新で本文を漏らさない
- **WHEN** 一覧表示中の正常レスが新たにNGになる
- **THEN** 同じ番号の非表示状態行へ切り替え、明示的な表示操作まで本文と画像を表示しない

#### Scenario: 非表示時の読み上げと画像読込
- **WHEN** 一覧に非表示のNGレスが含まれる
- **THEN** 本文・名前・ID・画像の内容を読み上げず画像を読み込まない
- **AND** 番号、NG状態、表示ボタンを読み上げとキーボードで識別でき、操作領域は48dp以上とする

#### Scenario: 未取得範囲を一覧に表示する
- **WHEN** 返信先一覧に未取得番号範囲がある
- **THEN** 取得済み候補の後に範囲を示す状態行を表示し、未取得番号を列挙しない
