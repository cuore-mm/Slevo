## ADDED Requirements

### Requirement: 設定項目選択メニューのアンカーオーバーレイ化
システムは設定画面内の選択式項目である全般のテーマ設定およびスレッド表示のデフォルト並び順設定を、`AnchoredOverlayMenu` で表示しなければならない（MUST）。メニューは押下された設定項目を基準に重ね表示し、既存の dismiss 契約を維持しなければならない（MUST）。

#### Scenario: 全般テーマ設定メニューがアンカー重ね表示される
- **WHEN** ユーザーが全般設定画面のテーマ設定項目を押下する
- **THEN** システムは `AnchoredOverlayMenu` をテーマ設定項目基準で重ね表示する

#### Scenario: スレッド並び順設定メニューがアンカー重ね表示される
- **WHEN** ユーザーがスレッド設定画面のデフォルト並び順項目を押下する
- **THEN** システムは `AnchoredOverlayMenu` をデフォルト並び順項目基準で重ね表示する

#### Scenario: 設定項目メニュー外タップや戻る操作で閉じる
- **WHEN** ユーザーが設定項目メニューの外側をタップするか戻る操作を行う
- **THEN** システムは `AnchoredOverlayMenu` を dismiss し、選択前の保存済み設定を維持する
