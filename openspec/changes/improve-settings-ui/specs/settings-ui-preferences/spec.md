## ADDED Requirements

### Requirement: テーマ設定の三状態選択
システムは全般設定でテーマを「ライト」「ダーク」「システムテーマに従う」の 3 つから選択できなければならない（MUST）。新規インストールまたはテーマ設定が未保存の状態では「システムテーマに従う」を既定値として扱わなければならない（MUST）。

#### Scenario: 未保存状態でシステムテーマが既定になる
- **WHEN** ユーザーがテーマ設定を保存していない状態でアプリを起動する
- **THEN** システムはテーマ設定を「システムテーマに従う」として扱う

#### Scenario: ライトテーマを選択する
- **WHEN** ユーザーが全般設定で「ライト」を選択する
- **THEN** システムはテーマ設定をライトとして保存し、アプリ表示をライトテーマにする

#### Scenario: ダークテーマを選択する
- **WHEN** ユーザーが全般設定で「ダーク」を選択する
- **THEN** システムはテーマ設定をダークとして保存し、アプリ表示をダークテーマにする

#### Scenario: システムテーマ追従を選択する
- **WHEN** ユーザーが全般設定で「システムテーマに従う」を選択する
- **THEN** システムはテーマ設定をシステム追従として保存し、OS の現在のテーマに合わせてアプリ表示を決定する

### Requirement: 既存ダークモード設定の削除
システムは既存の boolean ダークモード設定をテーマ設定の保存・読み取り契約から削除しなければならない（MUST）。新しい三状態テーマ設定が未保存の場合、既存 boolean 値を互換変換せず「システムテーマに従う」を適用しなければならない（MUST）。

#### Scenario: 既存ダークモード有効を互換変換しない
- **WHEN** 既存保存値でダークモードが有効、かつ新しいテーマ設定が未保存である
- **THEN** システムは既存 boolean 値を参照せず、テーマ設定を「システムテーマに従う」として扱う

#### Scenario: 新しいテーマ設定のみを保存する
- **WHEN** ユーザーがテーマ設定を選択する
- **THEN** システムは三状態テーマ設定のみを保存し、既存 boolean ダークモード設定を更新しない

### Requirement: 全般設定カードの統一表示
システムは全般設定画面のテーマ設定項目を `SettingsCardWithListItems` ベースのカード内リスト項目として表示しなければならない（MUST）。項目には現在選択中のテーマを supporting text として表示しなければならない（MUST）。

#### Scenario: 全般設定にテーマカードが表示される
- **WHEN** ユーザーが全般設定画面を開く
- **THEN** システムはテーマ設定をカード内のリスト項目として表示し、現在選択中のテーマ名を supporting text に表示する

### Requirement: テーマ選択メニューのアンカー表示
システムは全般設定のテーマ選択肢を `AnchoredOverlayMenu` で表示しなければならない（MUST）。メニューはテーマ設定項目を基準に表示され、外側タップまたは戻る操作で閉じなければならない（MUST）。

#### Scenario: テーマ設定項目から選択メニューを開く
- **WHEN** ユーザーが全般設定のテーマ設定項目を押下する
- **THEN** システムは「ライト」「ダーク」「システムテーマに従う」を含む `AnchoredOverlayMenu` を表示する

#### Scenario: テーマ選択後にメニューを閉じる
- **WHEN** ユーザーがテーマ選択メニュー内の選択肢を押下する
- **THEN** システムは選択したテーマ設定を保存し、メニューを閉じる

#### Scenario: テーマ選択済み項目を強調表示する
- **WHEN** システムがテーマ選択メニューを表示する
- **THEN** システムは現在選択中の項目を primary color、太字、右端チェックアイコンで表示する

### Requirement: スレッド表示設定カードの統一表示
システムはスレッド設定画面の表示設定項目を `SettingsCardWithListItems` ベースのカード内リスト項目として表示しなければならない（MUST）。デフォルト並び順の現在値は supporting text として表示しなければならない（MUST）。デフォルト並び順とミニマップ付きスクロールバー表示設定は、既存の保存・反映契約を維持しなければならない（MUST）。

#### Scenario: スレッド設定に表示設定カードが表示される
- **WHEN** ユーザーがスレッド設定画面を開く
- **THEN** システムはデフォルト並び順とミニマップ付きスクロールバー表示設定をカード内のリスト項目として表示し、デフォルト並び順の現在値を supporting text に表示する

#### Scenario: スクロールバー表示設定を切り替える
- **WHEN** ユーザーがミニマップ付きスクロールバー表示設定を切り替える
- **THEN** システムは既存と同じ保存先へ表示設定を保存し、スレッド画面でその設定を利用する

### Requirement: 並び順選択メニューのアンカー表示
システムはスレッド設定画面のデフォルト並び順選択肢を `AnchoredOverlayMenu` で表示しなければならない（MUST）。メニューは並び順設定項目を基準に表示され、外側タップまたは戻る操作で閉じなければならない（MUST）。

#### Scenario: 並び順設定項目から選択メニューを開く
- **WHEN** ユーザーがスレッド設定のデフォルト並び順項目を押下する
- **THEN** システムは「番号順」と「ツリー順」を含む `AnchoredOverlayMenu` を表示する

#### Scenario: 並び順選択後にメニューを閉じる
- **WHEN** ユーザーが並び順選択メニュー内の選択肢を押下する
- **THEN** システムは選択した並び順を既存と同じ保存先へ保存し、メニューを閉じる

#### Scenario: 並び順選択済み項目を強調表示する
- **WHEN** システムが並び順選択メニューを表示する
- **THEN** システムは現在選択中の項目を primary color、太字、右端チェックアイコンで表示する
