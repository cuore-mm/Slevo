## ADDED Requirements

### Requirement: タブ一覧アイテムのカード表示統一
システムはタブ一覧（板タブ一覧・スレッドタブ一覧）の各アイテムをカード状で表示しなければならないMUST。各カードの上段には、対象タブの識別に必要な情報（サービス名、板名、レス数）と閉じる操作を同一行で表示しなければならないMUST。

#### Scenario: 板タブ一覧でカード上段情報を表示する
- **WHEN** ユーザーが板タブ一覧を表示する
- **THEN** システムは各カード上段にサービス名、板名、関連する件数情報、および当該タブの閉じるボタンを表示する

#### Scenario: スレッドタブ一覧でカード上段情報を表示する
- **WHEN** ユーザーがスレッドタブ一覧を表示する
- **THEN** システムは各カード上段にサービス名、板名、レス数、および当該タブの閉じるボタンを表示する

### Requirement: スレッド新着表示のバッジ統一
システムはスレッドタブ一覧の新着レス数を、板画面の新着表示と同等のバッジ表現で表示しなければならないMUST。

#### Scenario: 新着レスがあるスレッドでバッジを表示する
- **WHEN** スレッドタブの新着レス差分が 1 以上である
- **THEN** システムは当該カード内に板画面と同等の強調バッジスタイルで新着件数を表示する

#### Scenario: 新着レスがないスレッドでバッジを非表示にする
- **WHEN** スレッドタブの新着レス差分が 0 である
- **THEN** システムは新着件数バッジを表示しない

### Requirement: 下部2段操作群への導線集約
システムはタブ一覧画面内の主要操作を下部2段レイアウトへ集約しなければならないMUST。上段は板/スレ切替操作、下段は左から順にタブ作成ボタンと更新ボタンの独立アイコンボタンで構成しなければならないMUST。

#### Scenario: 下部上段で板/スレを切り替える
- **WHEN** ユーザーが下部上段の板またはスレ切替を操作する
- **THEN** システムは対応する一覧ページへ遷移し、選択状態を視覚的に示す

#### Scenario: 下部下段でタブ作成と更新を操作する
- **WHEN** ユーザーが下部下段のタブ作成または更新アイコンを押下する
- **THEN** システムはそれぞれに対応する既存機能契約を実行する

#### Scenario: 板ページでは更新ボタンを表示しない
- **WHEN** 現在の一覧ページが板タブである
- **THEN** システムは下部下段の更新ボタンを表示しない

### Requirement: タブ一覧の更新導線一本化
システムはタブ一覧におけるプル更新機能を提供してはならないMUST NOT。更新導線は下部下段の更新ボタン操作へ統一しなければならないMUST。

#### Scenario: スレッド一覧を下方向にドラッグしても更新しない
- **WHEN** ユーザーがスレッドタブ一覧を下方向に引っ張る
- **THEN** システムはプル更新を開始せず、更新処理を実行しない

#### Scenario: 更新ボタンからのみ更新処理を開始する
- **WHEN** ユーザーが下部下段の更新ボタンを押下する
- **THEN** システムは開いているスレッドタブの更新処理を開始する

### Requirement: 下部操作群との非重なり保証
システムは一覧を末尾までスクロールした際、最下部アイテムが下部2段操作群に隠れないよう、一覧コンテンツ下端に十分な余白を確保しなければならないMUST。

#### Scenario: 最終アイテムが下部操作群に重ならない
- **WHEN** ユーザーが一覧を最下部までスクロールする
- **THEN** システムは最終アイテム全体を視認可能な状態で表示し、下部操作群との重なりを発生させない
