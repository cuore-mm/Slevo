## ADDED Requirements

### Requirement: タブ一覧下部操作群の Haze Masking
システムはタブ一覧画面の下部操作群に対して、背面コンテンツをぼかす Haze を適用しなければならないMUST。ぼかしは Masking により下端方向で効果が強まるグラデーションとして描画しなければならないMUST。

#### Scenario: 下部操作群の背景に段階的ぼかしを適用する
- **WHEN** ユーザーがタブ一覧を表示する
- **THEN** システムは下部操作群の背面を Haze でぼかし、上部より下部の方が効果が強いマスク表現で表示する

### Requirement: 下部アクションボタンの固定3スロット配置
システムは下部アクション列を3スロット（左予備、中央作成、右更新）で固定配置しなければならないMUST。板ページでは右スロットの更新ボタンを表示せず、同サイズのプレースホルダーを表示しなければならないMUST。

#### Scenario: 板ページで中央作成ボタン位置を固定する
- **WHEN** 現在ページが板タブである
- **THEN** システムは左スロットを予備領域として保持し、右スロットをプレースホルダーで確保したまま、作成ボタンを中央に表示する

#### Scenario: スレページで3スロットを実ボタン込みで表示する
- **WHEN** 現在ページがスレッドタブである
- **THEN** システムは中央に作成ボタン、右に更新ボタンを表示し、左スロットの予備領域を維持する
