## ADDED Requirements

### Requirement: タブ一覧下部操作群の Haze Masking
システムはタブ一覧画面の下部操作群に対して、背面コンテンツをぼかす Haze を適用しなければならないMUST。ぼかしは Masking により下端方向で効果が強まるグラデーションとして描画しなければならないMUST。

#### Scenario: 下部操作群の背景に段階的ぼかしを適用する
- **WHEN** ユーザーがタブ一覧を表示する
- **THEN** システムは下部操作群の背面を Haze でぼかし、上部より下部の方が効果が強いマスク表現で表示する

### Requirement: 下部操作群の固定3コンポーネント配置
システムは下部操作群を左から作成ボタン、中央の板/スレ切替、右の更新ボタンで固定配置しなければならないMUST。板ページでは右スロットの更新ボタンを表示せず、同サイズのプレースホルダーを表示しなければならないMUST。

#### Scenario: 板ページで作成・切替の位置を固定する
- **WHEN** 現在ページが板タブである
- **THEN** システムは左に作成ボタン、中央に切替スイッチを表示し、右はプレースホルダーで位置を維持する

#### Scenario: スレページで3コンポーネントを表示する
- **WHEN** 現在ページがスレッドタブである
- **THEN** システムは左に作成ボタン、中央に切替スイッチ、右に更新ボタンを表示する

### Requirement: 下部操作群領域のタップ干渉防止
システムはページ切替ボタンから下の下部操作群領域において、タップ入力を下層のタブ一覧へ透過させてはならないMUST NOT。空白領域タップは下部操作群側で消費しなければならないMUST。

#### Scenario: 下部操作群の空白領域タップがタブ一覧へ伝播しない
- **WHEN** ユーザーが下部操作群内のボタン以外の空白領域をタップする
- **THEN** システムは下層のタブカードタップ処理を実行せず、タブ遷移やタブクローズを発生させない

#### Scenario: 下部操作群のボタン操作は継続して実行できる
- **WHEN** ユーザーが下部操作群の作成または更新ボタンをタップする
- **THEN** システムは入力を下層へ透過させず、当該ボタンの既存契約のみを実行する
