## ADDED Requirements

### Requirement: 長押しメニューから並び替えへの連続遷移
タブ一覧は、カードの操作領域で長押しが成立した時点で既存アクションメニューを非操作状態で表示しなければならない（SHALL）。利用者が指を動かさず離した場合はメニューを操作可能にし、指を離さず追加のtouch slopを超えて移動した場合はメニューを閉じて同じpointer sequenceで並び替えへ移行しなければならない（SHALL）。

#### Scenario: 長押し後に指を離す
- **WHEN** 利用者がカードを長押しし、追加移動せず指を離す
- **THEN** タブ一覧は詳細、固定または固定解除、閉じるを選択できる既存メニューを表示したままにする

#### Scenario: 長押し後に指を動かす
- **WHEN** 利用者がカードを長押しし、指を離さず追加のtouch slopを超えて移動する
- **THEN** タブ一覧はメニューと長押し用floating cardを閉じ、元カードを表示して並び替えを開始する

#### Scenario: 長押し中の微小移動
- **WHEN** 長押し成立後の指移動が追加のtouch slop未満である
- **THEN** タブ一覧はメニュープレビューを維持し、並び替えを開始しない

### Requirement: 並び替えと既存ジェスチャーの優先順位
タブ一覧は、長押し成立前の通常タップ、横スワイプ削除、縦スクロールを既存どおり処理しなければならない（SHALL）。長押し成立後はスワイプ削除へ遷移してはならず（MUST NOT）、長押しからメニューまたは並び替えへ遷移した操作で通常タップを発火してはならない（MUST NOT）。

#### Scenario: 長押し前に横移動する
- **WHEN** 未固定タブ上のpointerが長押し成立前に横スワイプとして確定する
- **THEN** タブ一覧は既存のしきい値、速度、ラバーバンド、退出アニメーションでスワイプ削除を処理する

#### Scenario: 長押し前に縦移動する
- **WHEN** pointerが長押し成立前に縦スクロールとして確定する
- **THEN** タブ一覧はカード操作をキャンセルして親の縦スクロールへ入力を渡す

#### Scenario: 長押しメニューで通常タップを抑止する
- **WHEN** 利用者がカードを長押しして指を離し、操作可能メニューへ遷移する
- **THEN** タブ一覧は対象タブを開く通常タップを発火しない

### Requirement: closeボタン領域のジェスチャー分離
タブ一覧は、closeボタンをカードの並び替えおよびスワイプ削除の開始領域から除外しなければならない（SHALL）。closeボタンのタップは既存の削除処理だけを開始しなければならない（SHALL）。

#### Scenario: closeボタンを長押しする
- **WHEN** 利用者がcloseボタン領域を長押しまたはドラッグする
- **THEN** タブ一覧は並び替え、スワイプ削除、カード選択を開始しない

#### Scenario: closeボタンをタップする
- **WHEN** 利用者がcloseボタンをタップする
- **THEN** タブ一覧は既存の削除アニメーションを経て対象タブを閉じる

### Requirement: カード全体の押下表示
タブ一覧は、カード本体の操作領域で開始した通常タップまたは長押しの押下表示を、close/pin領域を含むカード全体へ表示しなければならない（SHALL）。押下表示の描画範囲を拡張しても、close/pin領域をカードの通常タップ、横スワイプ、並び替えの開始領域へ含めてはならない（MUST NOT）。

#### Scenario: カード本体を長押しする
- **WHEN** 利用者がカード本体の操作領域を長押しする
- **THEN** カード全体に押下リップルを表示し、close/pin領域もその表示範囲に含める

#### Scenario: closeボタンを長押しする
- **WHEN** 利用者がcloseボタン領域を長押しする
- **THEN** closeボタン自身の押下表示だけを表示し、カード全体の押下リップル、カード選択、スワイプ、並び替えを開始しない

### Requirement: 長押しメニューのPreviewとOpen状態
タブ一覧は、長押し中のメニュープレビューでは項目操作、外側タップによるdismiss、Backによるdismissを無効にしなければならない（SHALL）。指を離してメニューを開いた後は、これらの既存操作を有効にしなければならない（SHALL）。

#### Scenario: Preview中のメニュー項目を操作しようとする
- **WHEN** 長押し中のメニュープレビューが表示されている
- **THEN** メニュー項目はクリック、押下表示、アクセシビリティアクションを受け付けない

#### Scenario: Open後にメニュー項目を操作する
- **WHEN** 利用者が長押し後に指を離してメニューを開き、項目を選択する
- **THEN** タブ一覧は既存の詳細、固定または固定解除、閉じる操作を実行する
