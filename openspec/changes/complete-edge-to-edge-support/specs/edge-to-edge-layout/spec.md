## Purpose

アプリ内のすべての画面で背景とスクロール領域をウィンドウ端まで描画しながら、文字、操作ボタン、入力欄などの重要な UI をシステムバー、カットアウト、IME から一貫して保護する。

## ADDED Requirements

### Requirement: ウィンドウ端までの描画
アプリは、通常画面、一覧画面、詳細画面、設定画面および全画面オーバーレイの背景を、表示中のステータスバーおよびナビゲーションバーの背後を含むウィンドウ端まで描画しなければならない（SHALL）。

#### Scenario: システムバーが表示された通常画面
- **WHEN** ユーザーがステータスバーとナビゲーションバーを表示した状態で任意の通常画面を開く
- **THEN** 画面背景はシステムバー手前で途切れずウィンドウ端まで連続して描画される

#### Scenario: 一覧をスクロールする
- **WHEN** ユーザーが一覧画面を先頭または末尾からスクロールする
- **THEN** 一覧の描画領域とスクロール効果はアプリバーおよびシステムバーの背後まで継続する

### Requirement: 重要 UI の安全領域
アプリは、初期表示時の文字、ボタン、入力欄、一覧の先頭・末尾項目およびその他のタップ対象を、表示中のシステムバー、ディスプレイカットアウト、アプリ内の上部・下部バーに遮られない位置へ配置しなければならない（MUST）。

#### Scenario: 一覧の先頭と末尾を操作する
- **WHEN** ユーザーが一覧を先頭または末尾まで移動する
- **THEN** 先頭項目と末尾項目の表示内容およびタップ領域はシステムバーとアプリ内バーに遮られない

#### Scenario: カットアウトまたは横画面で操作する
- **WHEN** ディスプレイカットアウトがある端末または横画面で操作 UI を表示する
- **THEN** 重要な表示内容とタップ対象は安全領域内に配置される

#### Scenario: タブ一覧を最上部まで移動する
- **WHEN** ユーザーがタブ一覧を最上部までスクロールする
- **THEN** 先頭項目は上部操作群の占有領域の下へ配置され、検索・その他の操作ボタンと重ならない

### Requirement: アプリバーの一貫した余白
アプリは、上部バー、下部ナビゲーション、選択操作バーおよび検索操作バーに対してシステムバー領域を一度だけ反映し、同じ辺の Insets による過剰な空白を表示してはならない（MUST）。下部ナビゲーションの項目は、標準の表示寸法とタップ可能領域を維持しなければならない（MUST）。

#### Scenario: ジェスチャーナビゲーションを使用する
- **WHEN** ジェスチャーナビゲーション端末で下部ナビゲーションまたは下部操作バーを表示する
- **THEN** バーの背景は画面下端まで描画され、項目はジェスチャー領域に遮られず、ナビゲーションバー相当の余白が二重に現れない

#### Scenario: 3ボタンナビゲーションを使用する
- **WHEN** 3ボタンナビゲーション端末で下部ナビゲーションまたは下部操作バーを表示する
- **THEN** バーの背景と操作項目はナビゲーション領域に対して正しく配置され、項目が圧縮または切り取られない

### Requirement: IME 表示中の入力操作
アプリは、ソフトウェアキーボードの表示に合わせて利用可能領域を更新し、フォーカス中の入力欄と確定・検索・投稿などの主要操作を IME に遮られない状態にしなければならない（MUST）。システムバーと IME の重複領域を二重の余白として表示してはならない（MUST）。

#### Scenario: 下部検索欄でキーボードを開閉する
- **WHEN** ユーザーが下部検索欄へフォーカスし、IME を表示してから閉じる
- **THEN** 検索欄は両方の状態で操作可能な位置にあり、切り替えによる過剰な下余白が残らない

#### Scenario: タブ一覧上でURL入力ダイアログを開く
- **WHEN** ユーザーがタブ一覧のURL入力ダイアログで入力欄へフォーカスし、IMEを表示する
- **THEN** 背後のタブ切り替えなどの固定下部操作群はIMEの高さに応じて上へ移動せず、ダイアログ内の入力欄と確定操作はIMEに遮られない

#### Scenario: 投稿またはダイアログ入力を行う
- **WHEN** ユーザーが投稿 UI またはダイアログ内の入力欄へ文字を入力する
- **THEN** フォーカス中の入力欄と主要操作は IME に遮られず、必要に応じて内容をスクロールできる

### Requirement: システムバーの視認性
アプリは、通常画面の有効なアプリテーマに応じてステータスバーおよびナビゲーションバーのアイコン外観を設定し、背景とのコントラストを確保しなければならない（MUST）。画面固有の没入表示は終了時に通常画面の外観と可視状態を復元しなければならない（MUST）。

#### Scenario: アプリテーマを切り替える
- **WHEN** ユーザーがライトテーマとダークテーマを切り替える
- **THEN** ステータスバーとナビゲーションバーのアイコンは現在のアプリテーマ背景上で判読可能になる

#### Scenario: 画像ビューアを終了する
- **WHEN** ユーザーがシステムバー外観または可視状態を変更する画像ビューアを終了する
- **THEN** 遷移元画面に適したシステムバーの可視状態、アイコン外観およびコントラスト設定が復元される

### Requirement: 対応端末での一貫性
アプリは、対応する Android バージョンにおいて、ジェスチャーナビゲーション、3ボタンナビゲーション、縦画面、横画面および表示サイズ変更後も同じ安全領域要件を満たさなければならない（SHALL）。

#### Scenario: 構成を変更する
- **WHEN** ユーザーが画面を回転するかウィンドウサイズを変更する
- **THEN** 背景は新しいウィンドウ端まで描画され、重要 UI は更新後の安全領域内に再配置される
