## Why

タブ一覧に開いている板・スレッドが増えると、目的のタブを視覚的に探す必要があり、再訪したい板やスレッドへ素早く戻りにくい。タブ一覧上で板名・スレ名を横断検索できる導線を追加し、既存の検索入力 UI とタブ一覧の haze 表現を揃えることで、タブ管理の操作効率と画面一貫性を改善する。

## What Changes

- タブ一覧右上に検索ボタンを追加する。
- 検索ボタン押下時、右上検索ボタンを非表示にし、画面上部に検索バーを表示する。
- 検索モード中、下部の作成・板/スレ切替・更新/キャンセル操作群を非表示にし、更新進捗インジケーター用領域は表示を維持する。
- タブ一覧画面上部にも下部操作群と同様に Haze を適用する。
- 既存 `SearchBottomBar` の検索入力部分を共通化し、タブ一覧の上部検索バーから再利用する。
- 検索対象を板タブの板名、およびスレッドタブの板名・スレ名とし、大文字小文字とひらがな/カタカナを区別せずに絞り込む。
- 検索開始前のスクロール位置を保存し、検索解除時に元の位置へ復元する。
- Android の戻る操作で検索モードを終了できるようにする。

## Capabilities

### New Capabilities

- なし

### Modified Capabilities

- `tablist-ui`: タブ一覧に検索モード、上部検索バー、検索中の下部操作群制御、検索解除時のスクロール復元を追加する。

## Impact

- UI: `TabScreenContent`、`TabsPagerContent`、`OpenBoardsList`、`OpenThreadsList`、`TabListBottomControls`、`RemovableTabList`、新規タブ一覧上部検索コンポーネント。
- 状態管理: `TabsUiState` / `TabsViewModel` に検索モードと検索クエリを追加する。
- 共通 UI: `SearchBottomBar` の入力フィールド部分を共通化し、既存の板・スレッド画面検索 UI の挙動を維持する。
- 検索ロジック: タブ検索用の正規化・フィルタリング関数を追加し、既存 `toHiragana()` を活用する。
- テスト: タブ検索フィルタリング、検索モードの表示制御、戻る操作、スクロール位置保存/復元の観点を追加する。
