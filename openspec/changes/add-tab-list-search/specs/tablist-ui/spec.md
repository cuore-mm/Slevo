## ADDED Requirements

### Requirement: タブ一覧検索導線
システムはタブ一覧画面の通常表示時、画面右上に検索ボタンを表示しなければならないMUST。ユーザーが検索ボタンを押下した場合、システムはタブ一覧を検索モードへ切り替え、検索ボタンを非表示にして画面上部に検索バーを表示しなければならないMUST。

#### Scenario: 通常表示で検索ボタンを表示する
- **WHEN** ユーザーがタブ一覧画面を通常表示している
- **THEN** システムは画面右上に検索ボタンを表示する

#### Scenario: 検索ボタンで検索バーを表示する
- **WHEN** ユーザーがタブ一覧画面右上の検索ボタンを押下する
- **THEN** システムは検索ボタンを非表示にし、画面上部に検索バーを表示する

### Requirement: タブ一覧上部の Haze 表示
システムはタブ一覧画面上部の検索ボタン領域および検索バー領域に対して、背面コンテンツをぼかす Haze を適用しなければならないMUST。上部 Haze はタブ一覧下部操作群と同じ画面内 Haze source に基づいて表示しなければならないMUST。

#### Scenario: 通常表示の上部検索ボタン領域に Haze を適用する
- **WHEN** ユーザーがタブ一覧画面を通常表示している
- **THEN** システムは画面上部の端から端までの背面領域を Haze でぼかして表示し、右上に検索ボタンを表示する

#### Scenario: 検索モードの上部検索バー領域に Haze を適用する
- **WHEN** ユーザーがタブ一覧画面を検索モードで表示している
- **THEN** システムは上部検索バーの背面領域を Haze でぼかして表示する

### Requirement: タブ一覧検索中の下部操作群制御
システムはタブ一覧画面が検索モードの間、下部操作群の作成ボタン、板/スレ切替、更新ボタン、キャンセルボタンを表示してはならないMUST NOT。スレッドタブ更新中の進捗インジケーター領域は検索モード中も維持し、更新中であれば進捗を表示しなければならないMUST。

#### Scenario: 検索モードで下部操作ボタンを非表示にする
- **WHEN** ユーザーがタブ一覧画面を検索モードで表示している
- **THEN** システムは下部の作成ボタン、板/スレ切替、更新ボタン、キャンセルボタンを表示しない

#### Scenario: 検索モードでも更新進捗を表示する
- **WHEN** スレッドタブ更新処理中にユーザーがタブ一覧画面を検索モードで表示している
- **THEN** システムは下部の操作ボタン群を表示せず、更新進捗インジケーターを表示する

#### Scenario: 検索モードでない場合は既存の下部操作群を表示する
- **WHEN** ユーザーがタブ一覧画面の検索モードを終了する
- **THEN** システムは現在ページと更新状態に応じた既存の下部操作群表示へ戻す

### Requirement: タブ一覧検索入力の共通化
システムはタブ一覧の検索バーで、既存の検索ボトムバーと共通の検索入力部品を使用しなければならないMUST。共通入力部品は検索クエリ入力、検索終了、クエリ消去、音声入力、IME Search によるキーボード非表示を提供しなければならないMUST。

#### Scenario: タブ一覧検索バーでクエリを入力する
- **WHEN** ユーザーがタブ一覧上部の検索バーに文字を入力する
- **THEN** システムは共通検索入力部品を通じて検索クエリを更新する

#### Scenario: タブ一覧検索バーでクエリを消去する
- **WHEN** 検索クエリが入力済みで、ユーザーが検索バーの消去ボタンを押下する
- **THEN** システムは検索モードを維持したまま検索クエリを空にする

#### Scenario: タブ一覧検索バーから検索を終了する
- **WHEN** ユーザーがタブ一覧上部の検索バーの戻る操作を押下する
- **THEN** システムは検索モードを終了し、検索クエリをクリアする

### Requirement: タブ一覧検索の対象と正規化
システムはタブ一覧検索で、板タブの板名、およびスレッドタブの板名・スレ名を検索対象にしなければならないMUST。検索判定では大文字小文字、およびひらがな/カタカナを区別してはならないMUST NOT。

#### Scenario: 板名で板タブを検索する
- **WHEN** ユーザーが板タブ一覧で板名の一部に一致する検索クエリを入力する
- **THEN** システムは該当する板タブだけを一覧に表示する

#### Scenario: 板名でスレッドタブを検索する
- **WHEN** ユーザーがスレッドタブ一覧で板名の一部に一致する検索クエリを入力する
- **THEN** システムは該当する板名を持つスレッドタブだけを一覧に表示する

#### Scenario: スレ名でスレッドタブを検索する
- **WHEN** ユーザーがスレッドタブ一覧でスレ名の一部に一致する検索クエリを入力する
- **THEN** システムは該当するスレッドタブだけを一覧に表示する

#### Scenario: 大文字小文字を区別せず検索する
- **WHEN** ユーザーが検索対象文字列と大小文字だけが異なる検索クエリを入力する
- **THEN** システムは大小文字の違いを無視して該当タブを一覧に表示する

#### Scenario: ひらがなとカタカナを区別せず検索する
- **WHEN** ユーザーが検索対象文字列とひらがな/カタカナ表記だけが異なる検索クエリを入力する
- **THEN** システムはかな表記の違いを無視して該当タブを一覧に表示する

### Requirement: タブ一覧検索解除時のスクロール位置復元
システムはタブ一覧検索モードへ入る前に、板タブ一覧とスレッドタブ一覧のスクロール位置を保存しなければならないMUST。検索モード終了時、システムは検索開始前に保存したスクロール位置へ一覧を復元しなければならないMUST。

#### Scenario: 検索開始時にスクロール位置を保存する
- **WHEN** ユーザーがタブ一覧画面で検索ボタンを押下する
- **THEN** システムは板タブ一覧とスレッドタブ一覧の現在の先頭表示 item index と scroll offset を保存する

#### Scenario: 検索終了時にスクロール位置を復元する
- **WHEN** ユーザーがタブ一覧画面の検索モードを終了する
- **THEN** システムは検索開始時に保存したスクロール位置へ一覧を復元する

#### Scenario: 復元対象が現在の一覧範囲外の場合に安全に復元する
- **WHEN** 検索開始後にタブ数が変化し、保存したスクロール位置が現在の一覧範囲外になっている
- **THEN** システムはクラッシュせず、現在の一覧範囲内の有効な位置へスクロールする

### Requirement: 戻る操作によるタブ一覧検索終了
システムはタブ一覧画面が検索モードの間、Android の戻る操作で検索モードを終了しなければならないMUST。検索モード中の戻る操作は、検索終了を長押し選択解除より優先して処理しなければならないMUST。

#### Scenario: 戻る操作で検索モードを終了する
- **WHEN** ユーザーがタブ一覧画面を検索モードで表示している状態で Android の戻る操作を行う
- **THEN** システムは検索モードを終了し、検索クエリをクリアする

#### Scenario: 検索モードでない場合は既存の戻る操作を維持する
- **WHEN** ユーザーがタブ一覧画面を検索モードではない状態で表示している
- **THEN** システムは長押し選択解除など既存の戻る操作挙動を維持する
