## Why

タブ一覧では板/スレ一覧のページ切替が横スワイプに割り当てられており、個別タブを素早く削除する横スワイプ操作を追加できない。Issue #487 では、ページ切替を下部 switch 操作へ集約し、通常時のタブカード左右スワイプで未固定タブを削除できるようにする。

## What Changes

- タブ一覧の板/スレページ切替について、横スワイプによる切替を廃止し、下部の板/スレ切替 switch 操作のみで切り替える。
- 板タブ一覧・スレッドタブ一覧の各カードで、右から左方向への横スワイプでタブ削除を実行できるようにする。左から右のスワイプは削除対象外とする。
- カードのスワイプ移動量上限をカード幅とし、しきい値はカード幅に応じて動的に決定する。
- スワイプ削除確定時に、カードを左方向へ飛び出させる専用退出アニメーションを追加する。ボタンや長押しメニューによる削除は従来の `animateItem` 退出アニメーションを維持する。
- 固定済みタブはスワイプ削除できないようにし、既存の固定アイコン表示と閉じるボタン非表示の扱いを維持する。
- 長押し選択中、削除アニメーション中など通常時以外はタブカードのスワイプ削除を無効にする。
- 既存の閉じるボタンや長押しメニューによる削除フロー、タブ遷移挙動は維持する。

## Capabilities

### New Capabilities

- なし

### Modified Capabilities

- `tablist-ui`: タブ一覧の横スワイプ操作を、ページ切替ではなく未固定タブ削除として扱う要件を追加する。

## Impact

- UI: `TabScreenContent`、`TabsPagerContent`、`OpenBoardsList`、`OpenThreadsList`、`TabListCard`、`RemovableTabList` 周辺。
- State: `TabsUiState.isInLongPressSelectionMode` をスワイプ削除可否の制御に利用する。
- Data/API: 既存のタブ削除処理を流用するため、新しい永続化 API や外部依存の追加は想定しない。
- Tests: タブ一覧のページ切替、スワイプ削除、固定タブ、長押し選択中の無効化を確認するテストを追加または更新する。
