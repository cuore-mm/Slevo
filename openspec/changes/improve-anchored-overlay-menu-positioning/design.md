## Context

`AnchoredOverlayMenu` はアンカー位置に重ねて表示する汎用メニューとして導入されたが、用途が増えたことで「重ねる」「隙間を空ける」「上下を自動で切り替える」といった意図を明示しづらくなっている。さらに `offset` は水平/垂直の微調整をまとめて受け取るため、縦位置の意味が配置 enum や spacing と競合しやすい。

現在は `verticalSpacingPx` による gap 指定が `AnchoredTabActionMenu` で使われ、他の呼び出し元はデフォルト値や `offset` に依存し得る状態になっている。これにより、重ね表示の意図と非重なり表示の意図が混在し、維持が難しい状態になっている。

## Goals / Non-Goals

**Goals:**

- `AnchoredOverlayMenu` の縦位置指定を「重ね表示」「非重なり表示」「自動配置」で明示できるようにする。
- 縦方向の調整を `offset.y` ではなく、配置 enum と `verticalSpacingPx` に集約する。
- 既存の横方向微調整は、必要に応じて水平専用の明示的 API へ移行する。
- 既存呼び出し元の表示意図（重ねる/離す）を明示的に維持する。

**Non-Goals:**

- メニューのアニメーションやデザイン、アイコン表示を変更すること。
- `Popup` の表示仕様そのものを変更すること。
- 画面外クランプの挙動を完全になくすこと。
- 呼び出し元に任意の縦方向 nudge を残すこと。

## Decisions

### Decision: 縦位置の意図を明示できる enum を導入する

`Above` / `Below` / `Auto` に加えて、重ね表示用の `OverlapTop` / `OverlapBottom` を追加し、意図を明示する。

理由:

- 既存の `verticalSpacingPx` の符号だけでは意図が読み取りにくい。
- 重ね表示は UI 的に特殊なケースであり、呼び出し側で明示する方が安全。
- `Auto` は非重なり前提として扱いやすくなる。

代替案:

- `verticalSpacingPx` の符号だけで制御し続ける案は、既存と同様に意図が埋もれるため採用しない。

### Decision: `offset` を縦位置調整 API として使わない

`offset.y` による縦方向の微調整は廃止し、縦位置の制御は `verticalAlignment` と `verticalSpacingPx` に集約する。`offset` 自体も主要な位置調整 API としては非推奨化または削除対象とし、既存で必要な横方向の微調整は水平専用の明示的なパラメータへ移行する。

理由:

- `offset` は水平/垂直の意味をひとつの値にまとめるため、配置意図が読み取りづらい。
- 縦方向の重ね/非重なり/gap は配置 enum と spacing で十分表現できる。
- 任意の `offset.y` を残すと、呼び出し元ごとに暗黙の位置調整が増え、メニュー位置の一貫性が崩れやすい。
- 現在必要な非ゼロ調整は横方向のみであり、縦方向 offset を残す実利が小さい。

代替案:

- `offset.y` を反映して既存 API を完成させる案は、曖昧な API を温存するため採用しない。
- `offset` を残したまま利用規約だけで `y = 0` を求める案は、型で誤用を防げないため採用しない。

### Decision: 既存呼び出し元は明示的な配置指定に更新する

`AnchoredSelectionMenu` は重ね表示、`AnchoredTabActionMenu` は非重なり表示、他のメニューは従来通りの表示意図を明示的に指定する。

理由:

- デフォルトの挙動に依存すると、将来的な API 変更時に意図が崩れる。
- 呼び出し側のコードから表示意図を読み取れるようにする。

## Risks / Trade-offs

- [Risk] 既存のメニュー位置が微妙に変わる → 主要な呼び出し元に対して明示指定し、差分を最小化する。
- [Risk] `offset` 廃止/非推奨化で横方向微調整の表現先がなくなる → 水平専用 API を用意し、既存の横方向調整だけを移行する。
- [Risk] `Auto` が上下どちらを選ぶかで視覚的な一貫性が変わる → `Auto` は非重なり前提の利用箇所に限定する。

## Migration Plan

- `AnchoredOverlayMenu` の新しい縦位置指定を追加する。
- `offset` を廃止または非推奨化し、縦方向の位置調整から除外する。
- 既存の横方向微調整が必要な呼び出し元は、水平専用 API へ移行する。
- 既存の呼び出し元を、重ね表示か非重なり表示かに応じて明示的に更新する。
- 主要画面でのメニュー位置を確認する。

## Open Questions

- デフォルト配置を `Below` に変更するかは、既存画面の影響範囲を確認してから決定する。
