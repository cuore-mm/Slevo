## ADDED Requirements

### Requirement: タブ長押しアクションメニュー
システムはタブ一覧（板タブ一覧・スレッドタブ一覧）のカードを長押ししたとき、長押し対象カードに紐づくタブ専用の `AnchoredTabActionMenu` を表示しなければならないMUST。メニューは「詳細」「タブを固定」または「タブの固定を解除」「タブを閉じる」を表示し、「タブを閉じる」は破壊的操作として赤字で表示しなければならないMUST。

#### Scenario: 未固定タブを長押ししてメニューを表示する
- **WHEN** ユーザーが未固定の板タブまたはスレッドタブを長押しする
- **THEN** システムは長押しカード位置に紐づく `AnchoredTabActionMenu` を表示し、「詳細」「タブを固定」「タブを閉じる」を表示する

#### Scenario: 固定済みタブを長押しして解除メニューを表示する
- **WHEN** ユーザーが固定済みの板タブまたはスレッドタブを長押しする
- **THEN** システムは `AnchoredTabActionMenu` に「詳細」「タブの固定を解除」「タブを閉じる」を表示する

#### Scenario: タブを閉じる項目を赤字で表示する
- **WHEN** `AnchoredTabActionMenu` が表示される
- **THEN** システムは「タブを閉じる」を破壊的操作として赤字で表示する

#### Scenario: メニュー外操作で選択を解除する
- **WHEN** `AnchoredTabActionMenu` 表示中にユーザーがメニュー外をタップする
- **THEN** システムはメニューを閉じ、タブの長押し選択状態を解除する

### Requirement: 長押し選択中のタブ一覧表示
システムはタブ長押し選択中、長押ししたタブカードを通常より少し大きく表示し、それ以外のタブカードを通常より少し暗く表示しなければならないMUST。削除アニメーション中のタブカードでは、長押し選択操作を開始してはならないMUST NOT。

#### Scenario: 選択タブを強調表示する
- **WHEN** ユーザーがタブカードを長押ししてメニューを表示する
- **THEN** システムは長押ししたタブカードを通常より少し大きく表示する

#### Scenario: 非選択タブを減光表示する
- **WHEN** タブ長押し選択中に一覧内に他のタブカードが存在する
- **THEN** システムは長押し対象以外のタブカードを通常より少し暗く表示する

#### Scenario: 削除中カードでは長押し選択を開始しない
- **WHEN** タブカードが削除アニメーション中である
- **THEN** システムは当該カードの長押し選択状態を開始せず、アクションメニューを表示しない

### Requirement: 長押し選択中の下部操作群維持
システムはタブ長押し選択中も、タブ一覧画面の下部操作群を通常時と同じ表示で維持しなければならないMUST。タブ作成ボタン、更新ボタン、キャンセルボタン、ページ切替表示、およびスレッド更新中の進捗インジケータを、長押し選択状態だけを理由に非表示にしてはならないMUST NOT。

#### Scenario: 選択中も下部の主要操作ボタンを表示する
- **WHEN** ユーザーがタブカードを長押しして選択状態に入る
- **THEN** システムはタブ作成ボタン、更新ボタン、キャンセルボタンを通常時と同じ条件で表示する

#### Scenario: 選択中もページ切替インジケータを維持する
- **WHEN** タブ長押し選択中である
- **THEN** システムは板/スレページ切替の現在位置を示すインジケータを表示し続ける

#### Scenario: 選択中も更新進捗インジケータを維持する
- **WHEN** スレッドタブ更新中にユーザーがタブカードを長押しする
- **THEN** システムはスレッドタブ更新の進捗インジケータを表示し続ける

### Requirement: タブ詳細 BottomSheet 表示
システムはタブ専用アクションメニューの「詳細」選択時、タブ種別に応じた詳細 BottomSheet を表示しなければならないMUST。板タブでは `BoardInfoBottomSheet`、スレッドタブでは `ThreadInfoBottomSheet` を表示しなければならないMUST。

#### Scenario: 板タブの詳細を表示する
- **WHEN** ユーザーが板タブの `AnchoredTabActionMenu` で「詳細」を選択する
- **THEN** システムは対象板タブに対応する `BoardInfoBottomSheet` を表示する

#### Scenario: スレッドタブの詳細を表示する
- **WHEN** ユーザーがスレッドタブの `AnchoredTabActionMenu` で「詳細」を選択する
- **THEN** システムは対象スレッドタブに対応する `ThreadInfoBottomSheet` を表示する

#### Scenario: 詳細選択後にアクションメニューを閉じる
- **WHEN** ユーザーが `AnchoredTabActionMenu` の「詳細」を選択する
- **THEN** システムはアクションメニューを閉じ、長押し選択状態を解除したうえで詳細 BottomSheet を表示する

### Requirement: タブ固定状態の永続化と既存表示順の維持
システムは板タブおよびスレッドタブの固定状態を永続化しなければならないMUST。固定状態の有無によってタブ一覧の表示順を変更してはならずMUST NOT、タブ一覧はこれまで通り既存のタブ順に従わなければならないMUST。

#### Scenario: タブを固定する
- **WHEN** ユーザーが未固定タブの `AnchoredTabActionMenu` で「タブを固定」を選択する
- **THEN** システムは対象タブを固定状態として保存し、対象タブの表示位置は固定操作前の既存タブ順に従って維持する

#### Scenario: タブの固定を解除する
- **WHEN** ユーザーが固定済みタブの `AnchoredTabActionMenu` で「タブの固定を解除」を選択する
- **THEN** システムは対象タブの固定状態を解除して保存し、対象タブを通常タブとして表示する

#### Scenario: 固定状態を再起動後も維持する
- **WHEN** ユーザーがタブを固定した後にアプリを再起動する
- **THEN** システムは対象タブを固定済みとして復元し、固定状態に関係なく既存のタブ順で表示する

#### Scenario: 固定済みタブを通常タブより優先しない
- **WHEN** 固定済みタブと未固定タブが混在している
- **THEN** システムは固定済みタブを通常タブより上へ移動せず、固定状態追加前と同じタブ順規則で一覧を表示する

### Requirement: 固定済みタブの右上アイコン表示
システムは固定済みタブカードの右上に、閉じるアイコンの代わりに固定アイコンを表示しなければならないMUST。未固定タブカードでは既存通り右上に閉じるアイコンを表示しなければならないMUST。

#### Scenario: 未固定タブに閉じるアイコンを表示する
- **WHEN** タブカードが未固定状態である
- **THEN** システムはカード右上に閉じるアイコンを表示し、既存の閉じる操作を実行できるようにする

#### Scenario: 固定済みタブに固定アイコンを表示する
- **WHEN** タブカードが固定済み状態である
- **THEN** システムはカード右上の閉じるアイコンを固定アイコンに置き換えて表示する

#### Scenario: 固定アイコンは表示専用にする
- **WHEN** ユーザーが固定済みタブカード右上の固定アイコンをタップする
- **THEN** システムは固定解除、タブクローズ、タブ遷移などの操作を実行しない

#### Scenario: 固定済みタブをメニューから閉じる
- **WHEN** ユーザーが固定済みタブの `AnchoredTabActionMenu` で「タブを閉じる」を選択する
- **THEN** システムは対象タブの削除アニメーションを表示してからタブを閉じる
