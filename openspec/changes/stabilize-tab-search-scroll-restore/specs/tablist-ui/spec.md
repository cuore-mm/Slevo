## ADDED Requirements

### Requirement: タブ一覧検索スクロール復元状態の安定保持
システムはタブ一覧検索で検索結果表示へ切り替わる直前の板一覧・スレッド一覧のスクロール位置を、検索状態と同じタブ一覧 UI 状態スコープで保持しなければならないMUST。検索前スクロール位置は `TabScreenContent` の Composition 再生成だけで失われてはならないMUST NOT。

#### Scenario: 他画面から戻って検索解除してもスクロール位置を復元する
- **WHEN** ユーザーがタブ一覧で検索結果表示中に他画面へ移動し、その後タブ一覧へ戻って検索を解除する
- **THEN** システムは検索開始前に保存した板一覧・スレッド一覧のスクロール位置へ復元する

#### Scenario: Composition 再生成後も復元情報を維持する
- **WHEN** タブ一覧検索中に `TabScreenContent` が Composition から外れて再生成される
- **THEN** システムは検索前スクロール位置を維持し、検索解除時の復元に使用できる

#### Scenario: 復元対象が現在の一覧範囲外の場合に安全に復元する
- **WHEN** 検索結果表示中にタブ数が変化し、保存したスクロール位置が現在の完全リスト範囲外になっている
- **THEN** システムはクラッシュせず、現在の一覧範囲内の有効な位置へスクロールする

### Requirement: タブ一覧検索スクロール命令の一回消費
システムは検索解除時の復元と検索クエリ変更時の先頭表示を、タブ一覧 UI 状態から発行される一回限りのスクロール命令として扱わなければならないMUST。スクロール命令は UI が実行した後に消費され、同じ命令が再Compositionだけで再実行されてはならないMUST NOT。

#### Scenario: 検索解除時に復元命令を一度だけ実行する
- **WHEN** ユーザーが検索結果表示中に検索を解除する
- **THEN** システムは完全リストへ戻った後に保存済みスクロール位置への復元命令を一度だけ実行する

#### Scenario: 命令消費後に再Compositionしても再スクロールしない
- **WHEN** スクロール命令を実行済みのタブ一覧が再Compositionされる
- **THEN** システムは消費済みのスクロール命令を再実行しない

#### Scenario: 検索ワード変更時に現在表示中ページだけを先頭表示する
- **WHEN** ユーザーが検索クエリを非空の状態で変更する
- **THEN** システムは現在表示中ページの検索結果リストだけを先頭表示し、非表示ページのスクロール位置を変更しない

### Requirement: タブ一覧 BottomSheet の検索状態リセット
システムは板画面またはスレ画面から開いたタブ一覧 BottomSheet を閉じるとき、BottomSheet 内の検索モード、検索クエリ、検索前スクロール位置、未消費スクロール命令をクリアしなければならないMUST。BottomSheet を再表示したとき、前回の検索クエリだけが残った状態で表示してはならないMUST NOT。

#### Scenario: BottomSheet を閉じると検索状態を破棄する
- **WHEN** ユーザーがタブ一覧 BottomSheet を検索結果表示中に閉じる
- **THEN** システムは BottomSheet の検索モード、検索クエリ、検索前スクロール位置、未消費スクロール命令をクリアする

#### Scenario: BottomSheet 再表示時は検索なしで開始する
- **WHEN** ユーザーが検索中に閉じたタブ一覧 BottomSheet を再度開く
- **THEN** システムは検索モードではない状態でタブ一覧 BottomSheet を表示する

#### Scenario: 通常タブ一覧と BottomSheet の検索状態を独立させる
- **WHEN** ユーザーが通常タブ一覧とタブ一覧 BottomSheet を別々に表示する
- **THEN** システムはそれぞれの表示コンテキストで検索状態と検索スクロール復元状態を独立して管理する
