# Spec Delta

## Purpose

スレッド本文の安価を共通の規則で解釈し、返信関係・リンク操作・通知の参照先を一致させる。利用者がNGにしたレスを返信一覧と件数から除外し、件数表示と実際に確認できる返信を整合させる。

## ADDED Requirements

### Requirement: 単一と複数安価の共通解釈
システムは単一番号`>>n`、両端を含む昇順範囲`>>a-b`、カンマ区切り`>>a,b`およびその組合せを同じ安価として解釈しなければならない（SHALL）。参照先は本文の出現順、各範囲内は昇順で扱い、同一レス番号は重複させてはならない（MUST NOT）。この解釈を返信関係、安価タップ、返信通知で共通利用しなければならない（SHALL）。

#### Scenario: 範囲とカンマの参照先を求める
- **WHEN** 本文に`>>1-3,5`が含まれる
- **THEN** 参照先は1、2、3、5の順となり、返信関係と通知判定もその全番号を認識する

#### Scenario: 文中と複数表記の重複を除く
- **WHEN** 本文が`>>3 への返信。>>1,3`である
- **THEN** 参照先は3、1の順となり、3への返信は一度だけ数えられる
- **AND** 文中の安価も返信関係と通知判定の対象になる

### Requirement: 不正な参照と巨大範囲の安全な処理
システムは取得済みの同一スレッド内に存在する正のレス番号だけを返信関係や表示対象として解決しなければならない（SHALL）。0、逆順範囲、整数として表せない番号、不完全な範囲・カンマ表記は無効とし、それらを部分的な単一安価として解釈してはならない（MUST NOT）。巨大な範囲指定によって操作不能になってはならない（MUST NOT）。

#### Scenario: 巨大範囲を取得済みレスと照合する
- **WHEN** 100件取得済みのスレッドに`>>1-2147483647`が含まれる
- **THEN** 存在する1から100だけを解決し、範囲全体の列挙で処理が停止しない

#### Scenario: 無効な構文を先頭番号へ縮退させない
- **WHEN** 本文に`>>0`、`>>5-1`、`>>99999999999999999999`、`>>1-`、`>>1,`が含まれる
- **THEN** これらから参照先を生成せず、有効な別の安価と通常本文の表示は維持する

### Requirement: 複数安価タップによる参照先一覧
システムは範囲・カンマ形式の安価全体を操作対象とし、その安価が参照する表示可能な全レスを一つのポップアップで確認できるようにしなければならない（SHALL）。通常本文とポップアップ本文のどちらでもこの操作を提供し、対象がない場合は空のポップアップを追加してはならない（MUST NOT）。

#### Scenario: 複数安価の後半も操作できる
- **WHEN** `>>1,3`の後半部分をタップし、1と3が取得済みでNGではない
- **THEN** 1と3を対象とするポップアップが開く

#### Scenario: NGと未取得番号をリンク先から除く
- **WHEN** `>>1-3`をタップし、1がNG、2が未取得、3だけが表示可能である
- **THEN** ポップアップは3だけを表示する

### Requirement: NG除外済みの返信件数と返信一覧
システムはレス番号横の返信件数を、取得済み返信元からNGレスと重複番号を除いた件数としなければならない（SHALL）。同じ対象集合を返信一覧と返信元プレビューに使用し、件数はプレビューの最大表示件数に制限してはならない（MUST NOT）。この規則は番号順・ツリー順の本体およびポップアップに適用しなければならない（SHALL）。

#### Scenario: NG返信を件数に含めない
- **WHEN** あるレスへの返信が2、3、4であり、3がNGである
- **THEN** 返信件数は2件となり、返信一覧も2と4だけを対象にする

#### Scenario: 全返信がNGの場合
- **WHEN** あるレスへの返信元がすべてNGである
- **THEN** 返信件数は0件となり、返信ありを示す件数リンクと返信元プレビューを表示しない

#### Scenario: プレビューの上限を件数に適用しない
- **WHEN** NGでない返信が5件存在する
- **THEN** レス番号横の返信件数は5件であり、返信元プレビューは先頭3件となる

### Requirement: NG変更と取得結果への追従
システムはNGルールの追加・削除とスレッドの取得結果に応じ、再取得操作を要求せずに返信件数・返信一覧・プレビューを整合した状態へ更新しなければならない（SHALL）。レス番号は表示順やNG除外後の行位置ではなく、同一スレッド内の番号として維持しなければならない（SHALL）。

#### Scenario: NG追加と解除が即時反映される
- **WHEN** 表示中の返信元をNGに追加した後、そのNGルールを解除する
- **THEN** 件数・返信一覧・プレビューから同じレスが除外され、解除時には同じ番号で復帰する

#### Scenario: 追加取得と件数減少で安全に再計算する
- **WHEN** 新着返信を追加取得する、または再取得結果で既存のレス番号が存在しなくなる
- **THEN** 最新の投稿集合から返信関係を更新し、存在しないレスを表示せず、範囲外アクセスを発生させない
