# Spec Delta

## MODIFIED Requirements

### Requirement: 新着返信の判定
システムは、取得前に把握していた最新レス番号より後のレスのうち、本文の`>>n`、`>>a-b`、`>>a,b`またはそれらの組合せで同一スレッド内の確定済み自レス番号を参照するレスを返信として扱わなければならない（SHALL）。安価の参照先はスレッド表示と共通の解釈を使用し、文中の安価も対象としなければならない（SHALL）。返信レス自身も確定済み自レスである場合、または画面と共通のNG判定でNGとなる場合は通知対象から除外しなければならない（SHALL）。

#### Scenario: 他者から自レスへの返信を取得する
- **WHEN** 取得前の最新レス番号より後に、確定済み自レスを`>>n`で参照する他者のレスを取得する
- **THEN** システムはNGでないそのレスを通知対象の返信として検出する

#### Scenario: 複数の自レスを参照する一つの返信
- **WHEN** 一つの新着レスが複数の確定済み自レスを参照する
- **THEN** システムはNGでないその返信レス単位で一件の通知対象として検出する

#### Scenario: 自分自身による返信
- **WHEN** 新着レスが確定済み自レスを参照するが、その新着レス自身も確定済み自レスである
- **THEN** システムはそのレスを通知対象にしない

#### Scenario: 未対応の範囲アンカー
- **WHEN** NGでない新着レスが従来未対応だった`>>1-5`を含み、確定済み自レスが3である
- **THEN** システムは範囲内の3への返信として一件の通知対象を検出する

#### Scenario: カンマ安価と文中安価で自レスを参照する
- **WHEN** NGでない新着レスが`返信は >>1,3 を参照`を含み、確定済み自レスが3である
- **THEN** システムは3への返信として検出し、安価だけの行であることは要求しない

#### Scenario: 重複する範囲と単一安価
- **WHEN** 一つのNGでない新着レスが`>>1-5,3`と`>>3`を含み、確定済み自レスが3と5である
- **THEN** システムは返信レス単位で一件だけ検出し、参照された自レス番号も重複させない

## ADDED Requirements

### Requirement: 画面と一致するNG返信通知の抑止
システムはスレッド画面とタブ一括再取得の両方で、全板または該当板のID・名前・本文NGルールに一致する返信元レスから新規の利用者向け通知を生成してはならない（MUST NOT）。文字列・正規表現の一致規則は画面と共通にし、NGレスを除いても取得済み最新番号は通常どおり更新しなければならない（SHALL）。タイトルNGをレスNGへ拡張してはならない（MUST NOT）。

#### Scenario: 各種NGルールに一致する返信
- **WHEN** 全板または該当板のID・名前・本文のいずれかのNGルールに一致する新着返信を取得する
- **THEN** 本文プレビューを含む新規通知を生成せず、同じレスは画面側でもNGとして扱われる

#### Scenario: 別の板だけのNGルール
- **WHEN** 新着返信は別の板だけに適用されるNGルールに一致し、全板・該当板のルールには一致しない
- **THEN** そのルールだけを理由に通知を抑止しない

#### Scenario: タブ一括取得でもNGを適用する
- **WHEN** タブ画面から取得し、対象スレッドの画面が生成されていない
- **THEN** 同じ板とレス内容に対して同じNG判定を適用し、NG返信を通知しない

#### Scenario: NG解除後の遡及通知を防ぐ
- **WHEN** NGによって通知しなかった返信を取得済みとなった後、NGを解除して再取得する
- **THEN** その過去の返信を遡って通知せず、解除後の取得境界より新しい返信だけを判定する

### Requirement: 配信待ち通知のNG再確認
システムは配信待ち返信通知を提示する直前にもNG判定を確認し、NGとなった返信を抑止済みとして扱わなければならない（SHALL）。NG判定を確認できないときは本文を含む通知を提示せず、成功済みのスレッド取得を失敗にしてはならない（MUST NOT）。配信済み通知をNG変更だけで削除する機能は提供しない。

#### Scenario: 検出後にNGへ追加される
- **WHEN** 検出済みで未配信の返信が、配信前の確認でNGとなる
- **THEN** システムはその通知を提示せず抑止済みにし、後からNGを解除しても再配信しない

#### Scenario: NG確認に失敗する
- **WHEN** NGルールの読み取り失敗または元レスの未解決によって配信時の判定を確認できない
- **THEN** システムは通知を提示せず、取得成功状態と投稿一覧を維持する

#### Scenario: 配信済み通知のある状態でNGを変更する
- **WHEN** 既に配信済みの返信に対してNGルールを追加する
- **THEN** その通知の削除や通知履歴の書き換えは要求せず、以降の新規配信にNG判定を適用する
