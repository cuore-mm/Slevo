# about-screen-layout Specification

## Purpose
「このアプリについて」画面に表示するアプリ情報、操作項目、各操作の導線を定義し、ビルドバリアントごとの表示と既存操作の互換性を保証する。

## Requirements

### Requirement: アプリ情報ヘッダーの中央表示
「このアプリについて」画面は、画面上部にアプリアイコン、アプリ名、バージョンを中央揃えで表示しなければならない（MUST）。
アプリアイコンは現在のビルドバリアントに対応するランチャーアイコンを表示しなければならない。

#### Scenario: About 画面を開く
- **WHEN** ユーザーが「このアプリについて」画面を開く
- **THEN** アプリアイコン、アプリ名、バージョンが画面上部に中央揃えで表示される

#### Scenario: ビルドバリアント別アイコンを表示する
- **WHEN** About 画面が debug、ci、release など任意のビルドバリアントで表示される
- **THEN** そのビルドバリアントの `R.mipmap.ic_launcher` に解決されるアプリアイコンが表示される

### Requirement: 操作項目のカード表示
「このアプリについて」画面は、GitHub、ログ共有、OSS ライセンスの操作項目を `SettingsCardWithListItems` によるカード形式で表示しなければならない（MUST）。
各操作項目は、項目の役割を示す leading icon を表示しなければならない。

#### Scenario: 操作項目を表示する
- **WHEN** ユーザーが「このアプリについて」画面を開く
- **THEN** GitHub、ログ共有、OSS ライセンスの 3 項目がカード内のリスト項目として表示される
- **THEN** 各項目の左側に、その項目の役割を示す leading icon が表示される

### Requirement: 既存操作の維持
「このアプリについて」画面は、GitHub、ログ共有、OSS ライセンスの既存操作を維持しなければならない（MUST）。
レイアウト変更後も、各項目のクリック時の遷移先や処理は変更してはならない。

#### Scenario: GitHub 項目をタップする
- **WHEN** ユーザーが GitHub 項目をタップする
- **THEN** 既存の GitHub URL が外部 URI として開かれる

#### Scenario: ログ共有項目をタップする
- **WHEN** ユーザーがログ共有項目をタップする
- **THEN** 既存のログ共有 callback が呼び出される

#### Scenario: OSS ライセンス項目をタップする
- **WHEN** ユーザーが OSS ライセンス項目をタップする
- **THEN** 既存の OSS ライセンス画面への遷移 callback が呼び出される
